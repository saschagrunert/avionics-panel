# Avionics Panel rev 1: keyboard shortcuts

Generated by `python3 make_keys.py > KEYS.md`. The shortcut each function sends in the
[keyboard mode](../docs/using/keyboard.md). Ctrl, Shift and Alt are the left keys. Unit 2 shows a
shortcut only where it differs. Contains names the functions whose shortcut is part of the row's: the
same key with only some of its modifiers. If you bind one of them, bind the row too
([why](../docs/using/keyboard.md#binding)). The shortcuts are frozen once the table has been tested
on hardware: from then on new functions get new ones.
